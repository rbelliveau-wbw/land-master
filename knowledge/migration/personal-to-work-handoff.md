
# Personal ChatGPT to Work ChatGPT Handoff

## Durable state

All durable source, schema, rules, decisions, and incidents must live in this repository. The personal ChatGPT conversation can be used during initial migration, but no production workflow should depend on it afterward.

## Recreate in the work workspace

- Land Master Engineering Project
- company GitHub authorization
- Codex repository environment
- Zoho read-only metadata connection or MCP server
- shared skills, if used
- production approval ownership

Do not copy unrelated personal chats or personal files into the company workspace.
