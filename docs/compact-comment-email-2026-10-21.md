# Compact comment owner notification

The user selected Compact from the email mockups and explicitly retained
**View record in main list**. The existing
`buildContractCommentNotification(string commentId)` now renders that design
for Legal, Construction, Pro Forma, Budget and Project comments.

The record name is the primary heading below the New comment kicker. The author
and timestamp sit beside a fixed 38 × 38 initials badge in its own nested table.
The comment occupies a separate quoted block, so message height and wrapped
author/date text cannot stretch the badge. Initials use the first and last
name tokens (Robby Belliveau → RB); a single token retains one initial.
Both existing action links remain. The status/current-action line and ownership
explanation footer are removed from the rendered body.

Changes are restricted to presentation and initials in the existing builder.
Its exact persisted-parent lookup, recipient resolution/deduplication and author
exclusion, environment routing, subjects, result contract and read-only nature
remain unchanged. `postRecordComment`, mail dispatch, permissions and comment
records are untouched. No new form, field, workflow, function or Custom API.

Native Creator Development compiled and saved the function, then an independent
reload confirmed the new template. The native text before the initials and
after the body was byte-identical to the prior saved version. Offline tests
execute the actual Deluge body for all four parent fields and three environments,
recipient/permission boundaries, unchanged action URLs, escaped malicious and
multiline content, and fixed avatar structure. Desktop inspection uses HTML
generated by that body, including long author/date/comment fixtures. No real
comment or owner email was sent as a test.
