## Shared helper and security notes

The subsequent missing-actor audit found Land 8.13.6 could set live mode and begin loading with `(unknown)` after empty/array native context or an environment-only response; its actual initializer/runtime reproduced this offline. Budget 122.28.9 and Insights 1.5.37 block missing-actor business reads, and the Gantt 1.1.2 candidate has an equivalent guard. Insights' actual access guard made zero native API/report calls, but a fixture exposed that its initializer cached an unidentified connection and Refresh reused it. The narrow correction is implemented and independently reviewed locally: all four identical SDK2 runtime copies accept only string actors selected from native parameters or genuine SDK globals, clear prior context before validating a new handshake, and Land/Insights reject unidentified startup context before treating the connection as ready. Insights Refresh now performs a fresh handshake; its access rules are unchanged. Runtime/Land/Gantt/Budget/Insights focused suites passed, including actual bootstrap/authorization/runtime fixtures for invalid actor/context without business calls or mock data, genuine global fallback and fresh retry protected from expired context. Prepared Budget 122.28.10/Land 8.13.7/Insights 1.5.38 native gates remain pending. Five SDK1 startup paths also lack this client guard; preserve their API and permission contracts until the individual migrations. These observations do not demonstrate an anonymous or server-authorization bypass.

The canonical reader keeps IDs as strings, validates expected counts and cursors, limits concurrent SDK work to three, isolates user/environment query keys, and avoids publishing raw rows or criteria in its telemetry. Scoped invalidation now removes only matching cache/in-flight entries and prevents affected older completions from repopulating cache; unrelated in-flight deduplication remains available. Fresh reads also prevent late older cache overwrite, and settled tokens are released. Behavioral tests passed, synchronized copies are retained through Budget 122.28.9/Land 8.13.6/Insights 1.5.37, and the exercised native Development/Production startup gates passed. Current integrations keep TTL zero and do not cache permissions; no persistent-cache speedup is claimed. Invalidate before writes, retain invalidation on uncertain outcomes, keep eligibility/save verification fresh, and use controller generations to suppress stale UI rendering.

Local asset URLs now need both the mapped release and fetched-document fingerprint. All nine current source pages contain their configured version, and distinct currently mapped release versions have distinct HTML. The release-copy command now preflights config/version agreement, a requested HTML version marker and no matching HTML hash in prior release metadata before writing any target file. Helper-only future releases must update their HTML marker; immutable-target refusal is preserved. Temporary filesystem fixtures exercise both preflight and the actual CLI, including all nine current source formats; historical releases are not changed or revalidated. Some historical Contract/Tax/Gantt Stage pages lack their directory-version text. The fingerprint is a cache discriminator, not a security/authentication hash. Native `_lmh` presence verifies that the refreshed permanent loader includes this correction; earlier cached loader code cannot gain the new logic before being refreshed.

`LMData` includes `appLinkName` in its cache context. The three deployed SDK2 runtimes and the local Gantt candidate expose that authenticated name, with an actual-runtime cache-isolation test; adopt the same runtime in the five subsequent SDK1 migrations. Request history is capped at 500 entries; `requestCount` and response-size sum currently describe the retained window, not an unlimited session total. An additive summary or lean endpoint must not silently broaden user scope, authentication, environment reach, or writable record access. Retain attachment Custom API previews and ordinary-user file permission behavior. Avoid tokens, full access responses and private record/file contents in performance exports.
